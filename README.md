# crew

One Rust CLI over the agent runners (`claude`, `codex`, `agy`, `grok`), named background jobs, machine load, and provider credit usage.

The command name is `crew`. The alternatives were `roof` (the working title) and `span`. `desk`, `aide`, and `nest` were dropped because they are Homebrew formulas.

The plan is [PLAN.md](PLAN.md). Feature code waits until both orchestrators have acked that file's commit.
